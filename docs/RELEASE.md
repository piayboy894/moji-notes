墨记 Windows 1.1.0

- 按参考图重做书架：首页使用三色布纹笔记本封面，简化侧栏、最近记录和编辑页文案。
- 云端改为全局手动存档：新建、覆盖、读取和删除，包含全部记事本与记录；取消后台同步与自动合并。
- 本机继续自动加密保存；读取云存档或备份时整体替换项目数据，保留本机主密码、设备偏好和云连接。
- 与 Android 1.0.0 共用加密存档格式和数据仓库目录；支持手动读取旧版单文件云数据。

Intel / AMD 电脑下载 x64，Windows ARM 设备下载 ARM64。提供自包含 EXE、便携 ZIP、完整源码及原生测试截图。

当前 Windows 构建未附 Authenticode 发行者证书；这是独立于 Android 固定 APK 签名的配置。
