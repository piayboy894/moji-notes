墨记 Windows 2.0.0

- 正文整体替换为 Tiptap 官方 Simple Editor，与 Android 共用同一份离线编辑器。
- 引用、待办、列表、文字样式、链接、图片、撤销由开源编辑器统一处理，移除旧分块编辑器和自制表格。
- 保留提示词显式变量；手打花括号不触发变量。变量可完整删除、撤销并填值复制。
- 旧存档仍可读取，旧正文按普通文字原样显示，不兼容旧排版。
- 原生密码本、空白工作台、自定义记事本和四项手动全局云存档保留。
- 标准 EXE 内含 .NET 与离线编辑器，启用官方压缩，使用系统共享 WebView2；缺少 WebView2 时自动运行 Microsoft 官方安装引导程序，首次需要联网。
- 原先的完整离线 EXE / ZIP 保留为 `offline` 文件，适合无网络且没有 WebView2 的电脑。

本次保持 2.0.0，替换默认下载；已安装 2.0.0 需要关闭软件后重新下载覆盖，不会弹出同版本更新。功能、笔记和存档格式不变。源码 ZIP 与 BUILD-PROVENANCE 对应重新打包来源，原 Git 标签保持不动。

Windows 发行者代码签名证书未配置，系统可能显示未知发行者。Android 继续使用原固定证书。
