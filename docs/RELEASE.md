墨记 Windows 2.2.0

- 提示词填写区随正文接续、换行，长内容不再整块掉到下一行；支持中文输入、清空重填、普通文本粘贴、换行与撤销。
- 切换记录保留同一标题、工具栏和正文宿主，仅更新记录内容与状态；正文左侧与标题对齐，使用可用宽度。
- 统一下拉框、右键菜单、输入框、按钮、确认弹窗、滚动条与提示层；支持浅色、深色和 Windows 主题及屏幕缩放。
- 密码记录可在备注上方添加自定义属性，每项独立保存内容并支持复制，沿用明确的编辑/只读模式。
- 工作台与侧栏支持拖动记事本排序，共用保存的顺序；侧栏图标跟随记事本颜色。
- 回收站改为独立卡片网格，支持单选、复选框多选、鼠标框选、Ctrl / Shift 选择、批量还原与删除，并保留清空操作。

直接覆盖升级，保留本机数据和 GitHub 连接。新存档支持自定义属性和记事本顺序，继续读取旧存档；请将手机和电脑都升级至 2.2.0 后交换新存档。
标准 x64 独立 EXE 仍使用共享 WebView2，缺失时首次联网补装；另提供 ARM64 与便携 ZIP。
