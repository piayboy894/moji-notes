墨记 Windows 1.2.0

- 改为单一原生所见即所得编辑器，待办可勾选，表格可编辑与增删行列，支持格式、图片、链接、查找替换和撤销重做。
- 提示词变量只能通过「插入变量」创建，手打 `{{...}}` 保留为原文；复制全文输出可见文字。
- 删除演示、标签、主密码、本地加密、自动锁定和重复装饰文案；数据仓库默认为空。
- 统一矢量图标，提供自定义快捷键；修复收藏页更多菜单和新建记录的记事本归属。
- 密码直接显示、默认只读，点击「编辑密码」修改；删除显示切换、动态验证码与密码健康检查。
- 书架封面缩小，末尾虚线「＋」新建；颜色和图标可自定义，列表标题放大加粗。
- 修复已保存窗口关闭时的重入冲突，异常提示使用明确文案和重试、导出操作。
- 全局四种手动云存档保留，本机自动保存。旧版加密数据输入一次旧密码后迁移，之后直接打开。

Intel / AMD 选 x64，Windows ARM 选 ARM64。提供自包含 EXE、便携 ZIP、完整源码和原生测试报告。当前未附 Windows Authenticode 发行者证书。
