墨记 Windows 2.6.0

- 排查并修复后台恢复路径：编辑器使用有确认和超时的异步消息，恢复时唤醒挂起页面；编辑进程异常后重建并恢复已收到的正文。
- 后台加载确认不再等待动画帧；已收到的编辑独立自动保存，编辑器失联不会阻止这些内容写入本机。
- 新建记录只打开目标记录一次，标题可立即编辑；卡片预览使用有长度上限的扫描并复用，避免解析整份图片 HTML 阻塞界面。
- 进入记事本默认显示卡片网格，单击进入左侧列表与右侧编辑；编辑区左上角可返回，并保留搜索条件。
- 网格支持框选、复选框、Ctrl / Shift 多选、批量操作及多选拖入其他记事本；保留复制剪切快捷键。
- 卡片网格仅创建可见区域，过渡只动画位移和透明度，尊重系统关闭动画的设置。

覆盖升级保留本机数据。编辑器故障日志仅存本机，不包含正文、密码或 GitHub 令牌。
