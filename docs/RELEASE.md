墨记 Windows 2.3.0

- 插入图片后可选择白色、黑色、透明或透明网格背景，每张图片独立保存；选中图片时显示简洁的背景工具条。
- 新增六套主题：浅色「云白、暖纸、青瓷」，深色「曜石、深海、暮砂」。浅深模式分别记住选择，也可跟随 Windows。
- 重设中性色层次、正文与辅助文字、选中态、按钮文字、菜单和弹窗配色；编辑器与原生界面共用一套语义色，主题切换不重建正文。
- 记录卡片右下角新增小图钉，可直接置顶或取消置顶，允许多条；保留当前正文与编辑时间，置顶组内按当前排序。
- 图钉左边新增创建副本，记录右键菜单也可直接创建副本。正文、变量及自定义属性保留，副本获得独立记录身份，默认不置顶。

- 左侧回收站未选中时也可右键清空，无需离开当前页面；仍保留删除确认，空回收站时禁用。

直接覆盖升级，保留本机记录、GitHub 连接和存档。主题为本机偏好；云存档继续由你手动管理。
