# 架构

Windows 为 .NET 10 / WPF，Android 为 Kotlin / Jetpack Compose。记事本、导航、密码记录、文件选择、凭据存储、更新和全局云存档由原生层负责。正文只有一个 Tiptap 3.34.0 编辑器实例，使用官方 MIT Simple Editor 模板。

`editor/` 包含可构建的官方组件、固定依赖和原生桥接；`assets/editor/` 是提交到仓库的离线构建产物，两端均从这里打包。无 CDN、远程字体、Web 服务或 AI API。

## 文档与变量

每条新文档的 `content` 是 `<!--moji:tiptap:1-->` 加 Tiptap HTML。原生宿主不重建段落、引用、待办或图片，不接管 Enter、Backspace、选区和输入法。这些行为、样式和 SVG 工具图标来自官方编辑器。旧正文作为文字段落载入，不解析 Markdown 或旧表格结构；只有已登记的提示词变量会转换为原子变量节点。

变量节点记录 ID 和名称，禁用内部文本编辑，整个节点可删除、复制和撤销。文档每次变化同时提交内容和实际使用的变量列表，插入变量有独立的撤销边界。使用提示词时替换节点为用户填的文本，输入值不再次解释为变量或 HTML。普通 `{{` 没有特殊规则。

官方模板没有表格，项目移除旧的自制表格和查找替换工具。示例数据、外部字体、重复的主题切换和模拟图片上传被移除。图片通过系统选择器交给浏览器图像解码，最长边缩至 1800，必要时继续压缩，以 data URI 离线保存在当前文档，不写入外部图床。

## 桥接与持久化

JS 在文档更新时提交完整 HTML 和变量给宿主。Windows 使用 WebView2 `WebMessageReceived`，Android 使用带 `@JavascriptInterface` 的固定本地桥接。宿主核验记录 ID、空间代次、长度、文档标记和变量 ID，再执行本地自动保存。切换文档重新建立编辑状态和撤销历史。

保存、导出、云存档和后台切换先请求编辑器刷新，等待带令牌的确认再采集原生状态；释放 WebView 也等待刷新，避免最后一次输入丢失。读取存档更换空间代次，旧宿主的迟到消息不能覆盖新空间。

Windows 使用本地虚拟域名映射，Android 使用 WebViewAssetLoader 的本地 HTTPS 源。CSP 禁止外部连接和外部图片；外部页面不能导航进编辑器。用户点击“打开链接”时由原生层处理 HTTP / HTTPS。发行版不启用开发调试接口。

## 发行

Windows 单文件 EXE 内含 .NET、编辑器和经过 Microsoft 签名校验的离线 WebView2 CAB；优先使用已安装的 Evergreen，缺失时解压到本地应用目录，不要求另装浏览器。Runtime 下载地址和版本在 `assets/webview-runtime.json`，可以在后续发行更新。x64 原生冒烟测试强制使用包内 Runtime，ARM64 完成构建。

Android 继续沿用固定发行证书，后续 APK 可覆盖升级。系统 WebView 属于 Android 系统组件。数据采用同一文档格式，通过手动全局云存档跨端交换。发布工作流只发布验证成功的原始产物，不在发布时重新构建。
