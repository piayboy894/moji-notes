# 进度与验证范围

当前发布：Windows 1.2.1 / Android 1.1.1。两端安装包、源码、SHA-256 和原生验证报告已上传 GitHub Releases。

云存档已取消存档码，只需仓库和 Token，固定保存在 `moji-notes/saves/`。新建、覆盖、读取、删除仍完全由用户手动执行。已有连接中的旧密钥仅用于兼容旧存档；读取和覆盖转换均有测试，列表不会自动迁移或写入。

本轮在已发布 Android 1.1.0 APK 中复现了空白记录点击引用闪退，取得空引用日志，定位到优化后的 Ksoup HTML 解析回调。已保留该解析组件的回调类；结构插入改用原生编辑状态副本，先准备内容再替换，切换记录重置编辑器状态。图片读取移到后台，支持 30 MB 以内文件，缩放、校正方向并压缩保存，避免普通手机照片超过旧 2 MB 限制而失败。
