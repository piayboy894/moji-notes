# 2.2.0 交付

Windows / Android 2.2.0 已发布。提示词填写区现在是可随正文自然分行的行内文本，接续前文，空值使用淡色 placeholder。电脑端切换记录保留同一个标题控件、工具栏、固定转换行、正文宿主和浏览器；正文与标题左侧对齐。统一 Windows 下拉框、右键菜单、表单、确认窗、提示层与主题颜色，修复窄窗口密码复制按钮裁切和保留导航文字的深色主题对比度。

密码记录在备注上方支持独立自定义属性，可复制并沿用明确的编辑模式，内容进入历史版本和完整存档。工作台与侧栏可拖动记事本，共用持久化顺序；侧栏图标跟随主色。回收站移除右侧编辑区，使用独立卡片网格；Windows 支持单选、复选框、Ctrl / Shift 和矩形框选，Android 支持点选、复选框和长按多选，均支持批量还原、永久删除和清空。

# 2.1.0 交付
