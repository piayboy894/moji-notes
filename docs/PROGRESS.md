# 2.0.0 同版本包体与层级修正

Windows [构建验证 43723135636](https://github.com/piayboy894/moji-notes/actions/runs/43723135636)通过 35 项核心测试；执行官方安装程序的场景通过 10 项原生检查，随后已有组件的正常新进程启动通过 9 项原生检查，未执行安装程序。该测试机正常启动约 1.24 秒进入工作台，属于已有运行环境、已解包后的结果，不代表所有机器的首次启动速度。ARM64 已构建，未宣称经过 ARM64 真机测试。[发布 43723506993](https://github.com/piayboy894/moji-notes/actions/runs/43723506993)已替换默认附件，原 Git 标签未移动。

Android [编译与原生验证 43724845581](https://github.com/piayboy894/moji-notes/actions/runs/43724845581)通过 33 项单元测试、33 项共享编辑器检查和 10 项原生界面检查，包含真实长按选择、侧栏、提示层级及返回编辑。随后 [43726388090](https://github.com/piayboy894/moji-notes/actions/runs/43726388090)在应用、原生测试与资源完全不变的条件下复用同一 APK，完成独立安装、覆盖重装、旧数据读取、变量、系统图片选择、进程重开与真实 GitHub 更新反馈检查。正式包的前台窗口中已取得“你已在使用最新版本”；仅测试机延长无障碍提示时限以便自动采集，软件默认时限不改。正式设置页启用防截图，通过前台窗口无障碍树核对提示，原生调试界面的截图另行核对层级。[发布 43727160051](https://github.com/piayboy894/moji-notes/actions/runs/43727160051)已替换 APK，仍沿用原发行证书。

## 首次 2.0.0 编辑器替换交付

Windows / Android 均采用 Tiptap 3.34.0 官方 MIT Simple Editor，打包同一份离线资源。保留显式提示词变量；不保留旧编辑器排版兼容。旧存档继续读取，旧正文按普通文本原样显示。

共享编辑器 33 项检查通过，覆盖桌面、手机和平板尺寸的引用、待办、变量、图片、撤销、文档切换、旧文本读取、中文组合输入和旧版 WebView 光标回退。Windows 35 项核心测试及 9 项 WPF / WebView2 原生检查通过；Android 33 项单元测试及 9 项原生检查通过，包含两种硬件键盘/软键盘状态、退格换行、引用和待办退出、窗口缩放、旋转、数据保存与重开。

正式签名 APK 已在全新模拟器完成安装、覆盖重装、已发布 1.0.0 的完整原始正文迁移、变量插入、取消选图、系统文件选择器插入大图片及进程重启后的数据核对。图片、变量和正文重开后的实际截图已核对。原子变量和图片不会全部出现在 Android 可编辑文字无障碍值中，因此另核对实际保存节点、图片数据和截图。
