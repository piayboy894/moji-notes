# 2.5.0 记事本拖拽与记录操作

记事本的拖拽只呈现一个对象。Windows 把同一个原 Button 暂时移到顶层 Canvas，原面板留下等尺寸的空占位；没有截图替身，也不保留半透明原件。鼠标输入只更新指针位置，绘制帧统一更新位移。落点使用固定布局槽位和少量滞回，避免移动中的控件互相改变命中位置；邻居只有目标位置改变时才启动一次 150 毫秒让位动画。移动对象在顶层显示，不被滚动区域裁切；边缘按时间平滑滚动。

松手后原控件落到目标，再在同一布局批次放回面板；两处面板重排现有控件，不重建工作台、侧栏或编辑器。正常放下才提交顺序，Esc、失去捕获、窗口变化、切换页面会恢复。手机沿用成熟的 Reorderable 组件，使用局部临时顺序驱动同一个项目，不在每次跨位置时修改整个工作空间或写盘；结束提交一次，取消恢复。额外的缩放与重阴影已删除。

封面采用不透明底色。原 Windows 约 16% 和安卓 14% 的深色遮罩已移除，保留原有纸面、纹理、装订和自然阴影；主题只改变周围界面。

记录卡片底部仅保留置顶。创建副本位于右键 / 更多菜单，避免小图标误触。选中记录卡片时，复制 / 剪切 / 粘贴的默认键为 Ctrl+C / Ctrl+X / Ctrl+V，可在快捷键设置中修改。正文、标题、搜索框和账号字段保留原来的文本编辑；记录映射不会发给内嵌编辑器。

复制使用完整快照，副本获得独立身份，历史、置顶和收藏重置，标题自动避免重名。剪切在成功粘贴前不移除源记录；粘贴时读取最新源内容。移动保留身份、正文、自定义属性、历史、创建与编辑时间。整组记录与目标记事本必须同类型；任意不匹配、源缺失或空间变化都会在写入前拒绝，不产生部分移动。

记录剪贴板用于当前工作空间会话。系统剪贴板只放归属标识和标题，完整记录保存在软件内，避免大图片内容跨进程传输。普通文本复制会替换该标识；失效的记录剪贴板提示重新复制。

多选后可长按已选记录拖入侧栏。Windows 使用一组记录身份作为拖放数据；手机使用系统拖放和简洁数量标记，并展开侧栏。目标有匹配状态，落下时再次校验，正文不会接收记录拖放标识。放到原记事本不改变顺序或内容。

构建使用 `[build-native]` 提交标记，两个平台只生成和测试产物。检查通过并审阅截图后，`.github/verified-delivery.json` 明确记录平台、构建 ID 和来源提交；工作流再调用独立的校验发布器，发布已经验证的原始包。客户端读取的公开版本清单仍由正式发布自动维护。
