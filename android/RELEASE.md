墨记 Android 1.0.0 是 Kotlin + Jetpack Compose 原生客户端，最低支持 Android 8.0。

- 普通文本、提示词、账号密码三种记事本，采用三色布纹笔记本界面。
- 本机自动加密保存；全局云存档提供新建、覆盖、读取、删除，始终由用户选择，不自动同步或合并。
- 原生 Markdown 编辑预览、提示词变量、密码生成、TOTP、设备验证、搜索、历史版本、归档、回收站及导入导出。
- 按窗口尺寸适配手机、平板、横屏、窄窗口与超宽比例，支持键盘和鼠标；三星分屏、DeX 及双屏设备仍待真机验证。
- 固定发布密钥签名，未来更新保持相同签名身份。

下载 `Moji-Notes-Android-1.0.0.apk` 安装。若系统提示，请允许当前下载工具安装应用。已安装调试预览版的用户可导出加密备份，在正式版读取；调试版与正式版应用 ID 不同，可以同时存在。

源代码、SHA-256 校验值、公开签名证书指纹及原生正式包安装/覆盖安装测试报告随版本提供。
